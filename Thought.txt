本次实验首先对 Python 和 NumPy 的运行环境进行检查，确保相关工具能够正常使用。之后根据实验要求构建连续 6 个月的经营数据，使用 Python 列表分别保存月份、销售额、订单量和客户数量，并通过字典对各项指标进行整理和对应。接着使用 NumPy 将列表转换为一维数组，再将三个指标组合成二维数组，同时检查数组的 shape、ndim、size 和 dtype 等属性，确认数据结构符合要求。最后利用 NumPy 的基本统计方法计算销售额、订单量和客户数量的总和、平均值、最大值和最小值，并根据统计结果找出相应月份，分析经营数据的基本情况。

本次实验掌握了 Python 列表、字典以及 NumPy 数组的基本使用方法，能够完成一维数组和二维数组的创建与转换。通过对 shape、ndim、size、dtype 等属性的检查，对 NumPy 数组的基本结构有了更直观的认识，同时掌握了常用的统计计算方法。仍需进一步熟悉 NumPy 中其他数组操作和数据处理方法，提高独立编写和调试程序的能力。
